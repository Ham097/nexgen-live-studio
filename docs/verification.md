# Verification

## Tested on Windows

Laptop hardware inspected during implementation was an Intel Core i9-13900HX with 32 GB of RAM and an 8 GB NVIDIA RTX 4060 Laptop GPU. Windows WASAPI enumerated and opened the default physical microphone. That smoke check discarded the microphone frames while paused.

The real Chromium extension ran in a temporary browser profile against a synthetic Meet-shaped page. The app received the selected tab's 440 Hz signal while a different tab played a 997 Hz signal. The test exercised extension pairing, WebSocket framing, pause and restart, and fail-safe pause on tab closure. A synthetic spoken answer passed from the browser through tab capture, the audio worklet, CPU Whisper, and into SQLite as a student turn. Automated audio tests also injected a separate teacher channel and checked that pause and stale generation frames stayed out of the transcript.

The legacy Review Studio export was checked against `validateSessionRecord` and `deriveMetrics` from the local NexGen unified-platform checkout. The verification used fictional data and made no website or database changes.

## Local model benchmark

The benchmark ran three measured decodes per fixture after warmup. The table lists median decode times in seconds. Model load includes local model allocation and an encoder warmup. Source speech was generated by Windows SAPI. These numbers exclude capture buffering, transport, and UI latency.

| Model and device | Load | 10.935 s answer | 2.200 s beginner reply | 4.360 s speech with pause | 3 s silence |
| --- | ---: | ---: | ---: | ---: | ---: |
| base.en · CPU INT8 | 0.890 | 0.699 | 0.600 | 0.607 | 0.005 |
| large-v3-turbo · CUDA INT8/FP16 | 4.811 | 0.333 | 0.233 | 0.254 | 0.005 |
| distil-large-v3 · CUDA INT8/FP16 | 2.571 | 0.272 | 0.212 | 0.226 | 0.004 |

All models matched the 40 reference words in these fixtures and produced no text on digital silence. Distil was fastest on these fixtures. The laptop's existing compatible turbo cache was retained as the local default because this small scripted comparison does not distinguish the models' accuracy on learners. New installations default to the smaller base.en model. [Raw measurements](benchmark.json)

## How to reproduce

Run from the repository root with the virtual environment created by the launcher.

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
.\.venv\Scripts\python.exe -m scripts.screenshots
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\synthetic.ps1
.\.venv\Scripts\python.exe -m scripts.benchmark private/bench --models base.en
.\.venv\Scripts\python.exe -m scripts.review_studio_check C:\project\nexgen-unified-platform-v1
```

The three-model comparison also uses `Install NVIDIA acceleration.cmd` and the compatible model cache. The browser test requires Playwright 1.61 and a supported Chromium or Chrome for Testing executable. Run the base model benchmark first to populate the local benchmark cache.

```powershell
.\.venv\Scripts\python.exe -m pip install playwright==1.61.0
.\.venv\Scripts\python.exe -m scripts.browser_check C:\path\to\chrome.exe --voice private/bench/beginner.wav
```

## Acceptance still open

- A live Google Meet session with a consenting partner, normal playback, both physical channels, echo, overlapping speech, and hardware changes.
- Assessment against natural Turkish-accented learner speech, especially extended hesitations, fillers, brief replies and interruptions.
- A configured NexGen reservation and synchronization service. Current end-to-end validation uses local fixtures and a fake network acknowledgement.
- Long-duration recording and desktop usability in the teacher's normal environment.

The overlap check flags simultaneous channel energy for review. It does not identify a third participant or perform acoustic diarization. Grammar pattern candidates are conservative, and only teacher-confirmed constructions or tracked errors contribute to their confirmed counts. The pace chart requires comparable past evidence and a matching saved profile. Edited transcript text can contribute language evidence while its original timing is withheld until there is fresh word alignment.
