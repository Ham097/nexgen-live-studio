# Teacher guide

## Before a lesson

Open **Home**. Studio checks the microphone, speakers and local model while it looks for open Meet tabs. Choose **Connect Meet** to bring the intended call forward. Click the pinned Live Studio icon in Chrome, then confirm the learner and consent in Studio. Choose an existing learner to keep their evidence together. The schedule and previous lessons are under **Show saved lessons and schedule**.

Automatic input selection prefers a physical microphone and skips inputs like Stereo Mix and virtual cables. Apply a specific input in Settings if needed. The microphone stream starts with a recording or solo mic test. Tab audio serves as the student channel for a one-to-one call. Other people heard in that same tab require manual exclusion.

For a check without another person, use **Test on my own**. Start the microphone test and speak one sentence. The meter shows input and the words appear after a short pause. **Play a test sentence** checks Windows playback and transcription independently of the microphone.

## During the lesson

| Control | Result |
| --- | --- |
| **F8** or **Start/Pause** | Start a new sample or pause/resume the current one |
| **F9** or **Finish Sample** | End the current sample and save finalized text as the worker finishes |
| **Space** outside input controls | Start or pause while Studio is focused |
| **V** outside input controls | Focus the quick teaching entry |
| **Enter** while typing a teaching item | Save the item |
| **Transcript only** | Capture text for review without counting it in the assessment |
| **Floating toolbar** | Keep capture controls visible while using Chrome |

Watch the two audio indicators when you begin. If a tab disconnects or frames stop arriving, capture pauses. Reconnect the tab before resuming. If a microphone disconnects, select and apply the current device in Settings, then resume. The in-app recording label is explicit. Audio arriving during pause stays out of the transcription pipeline.

Use the three optional activities in any order or leave a sample unlabelled. You can reopen a finished or recovered sample from **Lesson Summary** while the lesson is a draft. A new recording window begins when you resume, so time spent paused stays out of the pace calculation.

## Before sharing

The original recognition stays available in **Review**. An edit to **What was said** changes vocabulary and grammar evidence. If wording changes, the app drops the old word alignment from timing metrics. **Teaching correction** supplies an example for instruction. When speech was assisted, mark it as such. Review an overlap or low-confidence flag only when you can verify the text. Use **Undo last change** to reverse a transcript review action.

Enter grammar error counts only for turns you reviewed. Reported errors use only the words in reviewed turns. Confirm the listed constructions separately after verifying how they were used. Mark **Independent** only when the learner used the language independently.

Teaching items begin private. Use **Edit** and select **Include on the student board and in exports** for material you want the learner to see. Select the dedicated **Student Presentation** window when sharing in Meet. Share an answer explicitly from Studio or Review to show it in that window.

## After the lesson

Finish the last sample and wait for processing. In Lesson Summary, exclude an unusable sample or reopen it with **Resume sample**. Choose **Passed**, **Further practice required**, **Insufficient evidence**, or **Review required**, then approve. A pace value does not determine CEFR achievement. The approved version is fixed and can be exported. Draft exports include the local transcript and private teacher fields, so handle them as learner records.

To check a real call, use a consenting test partner and headphones. Take turns speaking, then intentionally overlap. Pause and speak on both sides, resume and take another short answer. Check Chrome playback, the two channel labels, overlap flags, and that the paused words never appear. Finish both samples, edit a recognition mistake, and approve the local report. Changing audio devices and reconnecting the Meet tab can be tested on this same call.
